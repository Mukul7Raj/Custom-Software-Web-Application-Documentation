# FAQ

## General
**Q:** What does this project do?
**A:** It provides a minimal full‑stack example with a React frontend, FastAPI backend, and PostgreSQL database to demonstrate the software lifecycle from development to user hand‑off.

## Setup
**Q:** Do I need Docker?
**A:** No. You can run the backend and frontend locally without Docker (see *Getting Started*). Docker is provided for a quick one‑command local environment.

**Q:** How do I reset the database?
**A:** Stop the Docker containers, delete the `db_data` volume (`docker volume rm <project>_db_data`), and run `docker compose up` again. The `init.sql` script runs on first start.

## Usage
**Q:** How do I add new API endpoints?
**A:** Create new FastAPI route functions in `backend/app.py` and import any required models. Restart the backend to apply changes.

**Q:** How do I add new React pages?
**A:** Add components under `frontend/src/` and update the router (e.g., using `react-router-dom`).
