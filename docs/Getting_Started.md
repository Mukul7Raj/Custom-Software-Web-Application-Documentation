# Getting Started

## Prerequisites
- **Docker Desktop** (or Docker Engine) installed.
- **Node.js** (v18+) and **npm** for local frontend development (optional).
- **Git** for version control.

## Quick Start with Docker Compose
1. Open a terminal and navigate to the project root:
   ```
   cd "C:/Users/Mkr/Downloads/Custom Software Web Application & Documentation"
   ```
2. Build and start the containers:
   ```
   docker compose up --build
   ```
   This will:
   - Build the React frontend and serve it on `http://localhost:3000`.
   - Start the FastAPI backend on `http://localhost:8000`.
   - Launch a PostgreSQL database container accessible at `postgres://postgres:postgres@db:5432/appdb`.
3. Open your browser and visit:
   - Frontend: <http://localhost:3000>
   - API docs (Swagger UI): <http://localhost:8000/docs>

## Running Locally Without Docker (Development Mode)
### Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```
### Frontend
```bash
cd ../frontend
npm install
npm start
```
The frontend will proxy API requests to `http://localhost:8000`.

## Testing
- Backend tests (add your tests under `backend/tests/` and run `pytest`).
- Frontend tests (create with Jest/React Testing Library, run `npm test`).

## Deployment
- Use the provided `Dockerfile`s (in `frontend/` and `backend/`) to build images.
- Deploy to any container platform (e.g., Google Cloud Run, AWS ECS, Azure Container Instances).
